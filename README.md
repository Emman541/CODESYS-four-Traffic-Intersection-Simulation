# CODESYS-four-Traffic-Intersection-Simulation
A CODESYS-based traffic intersection simulation using PLC programming to control traffic lights and vehicle movement across a four-way intersection. The project demonstrates Structured Text (ST), timers, state-based control, and real-time traffic logic simulation.

## Features

* 🚦 Four-way traffic light control
* 🚗 Multiple cars moving through the intersection
* ⏱️ Timer-based traffic light switching
* 🛑 Cars stop when the traffic light is red
* 🟢 Cars continue when the light is green
* 🔄 Continuous traffic simulation

## Technologies Used

* CODESYS
* PLC Structured Text (ST)
* CODESYS Visualization

## Project Purpose

This project was created to practice **PLC programming, automation logic, timers, state control, and visualization** using CODESYS.

## Simulation

The simulation represents four directions:

* Top
* Right
* Bottom
* Left

Cars move through the intersection while following the traffic light signals.
